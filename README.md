# Buffet Karla Cintia

Landing page de captação (HTML/CSS/JS) para orçamentos via WhatsApp.

## Contatos

Edite `config.js` com o WhatsApp e Instagram reais:

```js
WHATSAPP_NUMBER: "5574999573778",
WHATSAPP_DISPLAY: "(74) 99957-3778",
INSTAGRAM_URL: "https://www.instagram.com/karla.cintia.almeida",
INSTAGRAM_HANDLE: "@karla.cintia.almeida",
```

## Rodar localmente

```bash
npm start
```

Abra `http://localhost:4173`.

## Imagens

Fotos otimizadas em `images/`. Para regenerar a partir das originais:

```bash
npm run optimize
```
